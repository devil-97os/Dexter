# Dexter face asset

`facecap.glb` is the Face Cap head model supplied to the Three.js project by the Face Cap creator, BannaFlak. The model is from the Three.js `r180` example asset at `examples/models/gltf/facecap.glb` and contains 52 ARKit-style facial morph targets. The Three.js example credits the model to [Face Cap](https://www.bannaflak.com/face-cap).

The model creator's MIT permission is recorded in the upstream project's third-party notice at [GNM Studio third-party notices](https://github.com/Saganaki22/GNM-Studio/blob/main/THIRD_PARTY_NOTICES.md). The `r180` file SHA-256 is `6BFCE6D0FCBB5839F5102B79733007859FEF7C5DF6D9EB49E2264542810B5F64`.

The Basis Universal transcoder files alongside the model are part of Three.js and remain under their upstream licenses. The relevant three.js project is available at [github.com/mrdoob/three.js](https://github.com/mrdoob/three.js).
